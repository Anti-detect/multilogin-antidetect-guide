## O que é Multilogin?

**Multilogin** é um **navegador antidetect** / **anti-detect browser** / **multi-login browser** corporativo. Cada **perfil** tem cookies, cache e **browser fingerprint** isolados.

**Multilogin X** — versão atual: equipes, Local API, **Mimic** (Chromium) + **Stealthfox** (Firefox), **Selenium / Playwright**.

### Cloud Phone

**Android real** na nuvem para apps (TikTok, Instagram, bancos). Cupom **MIN50**. Veja [cloud-phone-guide.md](../cloud-phone-guide.md).
