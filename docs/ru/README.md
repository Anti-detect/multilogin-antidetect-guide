## Что такое Multilogin?

**Multilogin** — корпоративный **антидетект-браузер** / **anti-detect browser** / **multi-login browser**. Каждый **профиль** изолирован: cookies, кэш и согласованный **отпечаток браузера** (canvas, WebGL, шрифты, часовой пояс).

**Multilogin X** — текущая версия: команды, Local API, **Mimic** (Chromium) + **Stealthfox** (Firefox), **Selenium / Playwright**.

### Cloud Phone

**Настоящий Android** в облаке для мобильных приложений (TikTok, Instagram, банки). Промокод **MIN50**. Подробнее: [cloud-phone-guide.md](../cloud-phone-guide.md).
