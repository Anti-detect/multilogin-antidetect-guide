## Multilogin คืออะไร?

**Multilogin** คือ **เบราว์เซอร์ antidetect** / **anti-detect browser** / **multi-login browser** ระดับองค์กร แต่ละ **โปรไฟล์** แยก cookies แคช และ **browser fingerprint** (canvas, WebGL, ฟอนต์, timezone)

**Multilogin X** — รุ่นปัจจุบัน: ทีม, Local API, **Mimic** (Chromium) + **Stealthfox** (Firefox), **Selenium / Playwright**

### Cloud Phone

**Android จริง** บนคลาวด์สำหรับแอปมือถือ (TikTok, Instagram, แอปธนาคาร) โค้ด **MIN50** ดู [cloud-phone-guide.md](../cloud-phone-guide.md)
