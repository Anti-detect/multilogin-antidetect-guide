# Getting started with Multilogin X

Checklist for your first week with an **antidetect browser** setup.  
Subscribe via [partner pricing](https://multilogin.com/pricing/?utm_source=saas&utm_medium=partner&a_aid=saas&a_bid=f5fad549) and apply **SAAS50** or **MIN50** (Cloud Phone) per [pricing-coupons.md](./pricing-coupons.md).

---

## Day 1 — account & client

1. Purchase or start trial from the [official pricing page](https://multilogin.com/pricing/?utm_source=saas&utm_medium=partner&a_aid=saas&a_bid=f5fad549) (partner link above).
2. Install the **Multilogin X** desktop app from the vendor dashboard only.
3. Enable 2FA on your Multilogin account.
4. Create a workspace folder naming scheme, e.g. `client-platform-account`.

---

## Day 2 — proxies

1. Buy **residential or mobile** proxies matching target country/city.
2. Assign **one proxy per sensitive profile** — do not rotate randomly mid-session.
3. Align profile **timezone** and **language** with proxy geo.
4. Test IP leak pages inside a fresh profile before real logins.

---

## Day 3 — first profiles

1. Create two test profiles: one **Mimic**, one **Stealthfox**.
2. Use auto fingerprint first; tweak only if a site blocks you.
3. Import cookies only from trusted backups.
4. Label profiles in a spreadsheet (profile ID, proxy, platform, owner).

---

## Day 4 — team (if applicable)

1. Invite teammates with least-privilege roles.
2. Document who may launch vs edit vs delete profiles.
3. Agree on a “no manual login on host machine Chrome” rule.

---

## Day 5 — automation (optional)

1. Read Multilogin’s official **Local API** documentation in your plan.
2. Prototype **Playwright** or **Selenium** attach to a running profile on a dev machine.
3. Keep human-like delays; avoid parallel aggressive logins on one IP.

---

## Day 6–7 — Cloud Phone (optional)

1. If you need TikTok/IG/banking apps, add **Cloud Phone** and try **MIN50** at checkout.
2. Treat each cloud device like a physical phone: don’t factory-reset casually.
3. Match mobile proxy country to store locale when possible.

---

## Common mistakes

| Mistake | Fix |
|---------|-----|
| Same proxy on 50 profiles | Spread risk; use pool with 1:1 for high-value accounts |
| Mixing personal Chrome logins | Use only Multilogin profiles for work accounts |
| Random fingerprints per launch | Keep profile persistent |
| Skipping coupon field | Apply **SAAS50** / **MIN50** before pay |
