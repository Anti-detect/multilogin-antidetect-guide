## 什么是 Multilogin？

**Multilogin** 是企业级 **反检测浏览器** / **指纹浏览器** / **多开浏览器**：每个 **配置文件（profile）** 独立 cookies、缓存和 **浏览器指纹**（Canvas、WebGL、字体、时区等），用于管理多个账号（电商、广告、社媒、代理业务）而不互相关联。

**Multilogin X** 为当前版本：团队权限、本地 API、**Mimic**（Chromium）与 **Stealthfox**（Firefox），支持 **Selenium / Playwright** 自动化。

### Cloud Phone

云端 **真实 Android** 运行原生 App（TikTok、Instagram、银行 App 等）。购买时使用 **MIN50**。详见 [cloud-phone-guide.md](../cloud-phone-guide.md)（英文）。
