## Apa itu Multilogin?

**Multilogin** adalah **browser antidetect** / **anti-detect browser** / **multi-login browser** tingkat enterprise. Setiap **profil** punya cookies, cache, dan **browser fingerprint** terpisah (canvas, WebGL, font, timezone).

**Multilogin X** — versi terbaru: tim, Local API, **Mimic** (Chromium) + **Stealthfox** (Firefox), otomasi **Selenium / Playwright**.

### Cloud Phone

**Android asli** di cloud untuk app mobile (TikTok, Instagram, banking). Kupon **MIN50**. Detail: [cloud-phone-guide.md](../cloud-phone-guide.md).
