# Multilogin Cloud Phone guide

**Cloud Phone** = real **Android** environments in the cloud (not a desktop browser profile). Use for TikTok, Instagram, mobile banking, app-only KYC, etc.

**Coupon:** **`MIN50`** at checkout (Cloud Phone eligible plans).  
**Pricing:** [partner link](https://multilogin.com/pricing/?utm_source=saas&utm_medium=partner&a_aid=saas&a_bid=f5fad549)

Browser-only plans use **`SAAS50`** — see [pricing-coupons.md](./pricing-coupons.md).

---

## Cloud Phone vs browser profile

| | Browser profile (Mimic / Stealthfox) | Cloud Phone |
|---|--------------------------------------|-------------|
| Runs | Websites in antidetect browser | Native Android apps |
| Fingerprint | Desktop browser stack | Mobile device + apps |
| Best for | Meta Ads Manager, Amazon Seller Central | TikTok app, IG app, mobile wallets |
| Typical coupon | **SAAS50** | **MIN50** |

You can run **both** in one Multilogin stack when a workflow spans web dashboards and mobile apps.

---

## Setup tips

1. Match **mobile proxy** country to app store / account region.
2. Keep the same cloud device for an account — avoid “new phone every day” patterns.
3. Install apps only from official stores inside the device flow Multilogin documents.
4. Do not mix personal phone SIM logins with farmed accounts on the same device identity.
